# Eva Travel Morocco

A premium travel agency web application and interactive guide for Eva Travel Morocco — specializing in bespoke private tours, Sahara desert expeditions, imperial city circuits, and curated travel guidebooks across Morocco.

## Overview

Eva Travel Morocco provides international travelers with personalized travel experiences across Morocco. The platform offers comprehensive tour itineraries, detailed travel guidebooks (Marrakech, Fes, Chefchaouen, Sahara), verified customer reviews, licensing credentials, and interactive booking inquiries.

## Key Features

- **Curated Morocco Tours**: Tailored multi-day itineraries covering the High Atlas Mountains, Sahara Desert bivouacs, coastal Essaouira, and northern heritage cities.
- **Dynamic Tour Detail Pages**: Itinerary timelines, highlights, included services, and booking requests.
- **Morocco Travel Guidebooks**: Rich editorial guidebooks with practical travel advice, cultural etiquette, packing tips, and local secrets.
- **Trust & Verification Badges**: Verified traveler reviews (Google & TripAdvisor), Ministry of Tourism certification details, and sustainable travel initiatives.
- **Multilingual Experience**: Interactive language switching (English, French, Spanish) for international visitors.
- **Cutting-Edge Tech**: TanStack Start & TanStack Router for fast routing and modern React 19 architecture.

## Technologies Used

- **React 19**
- **TypeScript**
- **TanStack Start & TanStack Router** (Type-safe client/server routing)
- **TanStack Query** (Data caching & management)
- **Tailwind CSS v4**
- **Radix UI** (Headless accessible UI components)
- **Lucide React** (Icons)
- **Vite**

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ahmedamarir-aseven/eva-travel-agency.git
   cd eva-travel-agency
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
